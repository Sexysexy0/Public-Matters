# Alternatives Comparison

Compare alternatives using the same assumptions and time horizon:

- BNPP rehabilitation.
- New large reactor.
- Small modular reactors.
- Geothermal, hydro, solar, wind, storage, efficiency, and transmission upgrades.

## Required dimensions

Reliability, lifecycle cost, construction time, emissions, land and water use, safety, waste, resilience, financing risk, local capability, grid fit, and reversibility.
