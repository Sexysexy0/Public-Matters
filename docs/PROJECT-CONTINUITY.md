# Project Continuity Framework

## Signal Origin

2026-09-20: California High-Speed Rail investigation (Nick Shirley)
- $15B spent, no operating trains
- Cost overrun to $236B
- AB2624 — "Stop Nick Shirley Act" limits recording
- Directly addresses: institutional discontinuity

## The Pattern

    Public funds → Political promise → Administration change
        ↓
    Project stalls → No output → Citizen asks
        ↓
    Investigator exposes → Legal hurdle created
        ↓
    Silence → Waste continues

## The Solution — 3 Contracts

### 1. ProjectContinuityRegistry
Tracks government/institutional projects on-chain:
- Budget, disbursements, milestones
- Cancellation attempts require 2-of-N approval
- Public audit trail

### 2. ContinuityGuard
Protects projects from arbitrary cancellation:
- 2/3 supermajority required
- 30-day public notice period
- Immutable cancellation log

### 3. InvestigatorShield
Protection for investigators and whistleblowers:
- Register investigators with ZK-commitment
- Submit anonymized evidence
- Track suppression laws (AB2624-type)

## Integration

    Project registered
        ↓
    Disbursements + milestones recorded
        ↓
    Cancellation attempt requires:
        - 2/3 approval
        - 30-day public notice
        - Reason on-chain
        ↓
    Investigator submission + protection
        ↓
    Public audit trail

## Applied To

- **California HSR** — pattern documentation
- **Philippine infrastructure** — CASE-006 in ph-reform
- **Any jurisdiction** — reusable framework

## Legal Boundary

Proposals + framework only. No authority to override
existing legal systems. Tools for accountability, not mandates.
