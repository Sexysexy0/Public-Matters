# World Signals → Design Principles

This folder captures world observations (news, posts, topics) that map to
design principles in our governance stack.

## Purpose

Not fact-checking. Not verification. **Shared pattern observation.**

## Workflow

1. **Source** — What did we see?
2. **Pattern** — What underlying theme?
3. **Principle** — What governance rule?
4. **Alignment** — What existing contract/design maps?
5. **Gap** — What's missing?
6. **Artifact** — What file/schema/test to add?

## Files

Each signal gets its own file: `YYYY-MM-DD-slug.md`
