# Contribution Guidelines

We welcome contributions to the Sexysexy0 organization.  
All contributions must align with the governance and compliance standards declared in OWNERSHIP.md.

## Process
1. Fork the repository.
2. Create a feature branch (`git checkout -b feature/your-feature`).
3. Ensure tests pass (`forge test -vvv`).
4. Submit a pull request with clear description.

## Standards
- Code must compile with zero warnings.
- All contracts must include events for critical state changes.
- Security checks (reentrancy, access control) are mandatory.
- Documentation updates required for new features.
